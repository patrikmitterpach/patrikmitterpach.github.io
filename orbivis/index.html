[ notes ]

Orbit Visualizer projects a satellite's current position and surrounding ground track onto an equirectangular world map. The default object is the International Space Station; paste any current two- or three-line element set to track something else.

What is a TLE?

A two-line element set is a compact text format describing an Earth-orbiting object's orbit at a specific epoch. Orbit trackers propagate that data forward and backward in time. TLEs age quickly, so use a current one from Celestrak for accurate positions.

How is the ground track calculated?

Positions come from the SGP4 model in the vendored tle.js and satellite-js libraries. The map uses a simple equirectangular projection, not Mercator, so latitude spacing stays uniform. Ground-station coverage is a great-circle radius drawn by sampling its circumference.

Why does the map update once per second?

The canvas is redrawn on a one-second timer rather than continuously animated. This keeps CPU use low, and every frame is still calculated for the timestamp shown below the map.
